# 🛒 Supermarket Sales Analysis  

## 📌 Project Overview  
This project analyzes **supermarket sales data** to uncover insights into customer purchasing patterns, sales trends, and store performance. The analysis is conducted using **Excel and SQL**, leveraging data visualization, calculations, and querying techniques.  

## 📂 Dataset  
The dataset contains transaction details from a supermarket, including:  
- **Invoice ID**  
- **Branch & City**  
- **Customer Type & Gender**  
- **Product Categories**  
- **Quantity & Total Cost**  
- **Payment Methods**  
- **Ratings & Timestamps**  

## 🔍 Key Features  

### ✅ **Excel Analysis**  
- **Data Cleaning & Formatting**  
- **Conditional Formatting for Insights**  
- **Sales Performance Analysis (Total Revenue, Avg. Sales per Customer, etc.)**  
- **Pivot Tables & Charts for Visualization**  
- **Attendance Tracking & Trend Analysis**  

### ✅ **SQL Queries & Analysis**  
- **Data Extraction & Filtering**  
- **Revenue Trends & Top-Selling Products**  
- **Customer Segmentation Based on Purchase Behavior**  
- **Branch & Payment Method Performance**  

## 📊 Tools & Technologies Used  
- **Microsoft Excel** (Data Cleaning, Pivot Tables, Charts, Conditional Formatting)  
- **SQL Server** (Data Queries, Transformations, Aggregations)  

## 📈 Visualizations  
The project includes **column charts, pivot tables, and trend analysis graphs** to present insights clearly.  

## 🚀 How to Use  
1. **Download the Dataset** and open the **Excel file**.  
2. **Explore the pivot tables and charts** to analyze sales trends.  
3. **Run SQL queries** on a database to extract insights.  

## 📜 Conclusion  
This project demonstrates **real-world data analysis skills** using **Excel & SQL**, helping businesses make **data-driven decisions** to optimize sales and customer experience.
